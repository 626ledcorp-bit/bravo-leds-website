How it works

  • Two steps, always. Upload → every row is validated and shown as create / update / error → you confirm. If any row has an error, nothing is written until the file is fixed and re-uploaded.
  • Matching. An existing product is matched by its product sku; an existing variation is matched by variation_sku, or by its option values when no variation SKU is given. Unknown SKUs in an inventory import are errors. A product without a SKU can never be matched — re-importing it creates a duplicate, so give every product a SKU before bulk-editing via export.
  • Blank cells. On update, a blank cell keeps the existing value — only cells you fill in are overwritten. On create, blanks take the defaults (status draft, taxable yes, 1-year warranty, placeholder stock). An explicit 0 in quantity sets stock to zero. CSV cannot clear an optional text field — use the product form for that.
  • Prices. price is the selling price. If compare_at_price is also given, price becomes the sale price and compare_at_price the regular (struck-through) price. Same for variation_price / variation_compare_at.
  • Rows & variations. Rows sharing one product sku are one product. Any row with option values (option1_name/option1_value, up to 3 options) or variation columns creates/updates a variation. Imports never delete variations — remove them on the product form.
  • Names. “Bravo ” is prepended automatically when missing. Names containing “headlight”, “off-road” or “offroad” are rejected (off-road wording is fine in the description).
  • Validation. Price must be > 0, category must exist, duplicate SKUs inside the file are rejected, and unknown column headers are rejected (typo guard).
  • Private fields. cost, msku, supplier fields and notes stay admin-only — they never appear on public pages, in carts, or in customer emails.

Full-import columns

name, sku, msku, barcode, category, product_type, tier, price, compare_at_price, cost, vendor, weight_oz, length_in, width_in, height_in, quantity, low_threshold, taxable (yes/no), status (active/draft/archived), description, blurb, features (| separated), tags (comma separated), seo_title, seo_description, fitment_positions (comma separated), badge, warranty, supplier_name, supplier_sku, supplier_notes, notes, option1_name, option1_value, option2_name, option2_value, option3_name, option3_value, variation_sku, variation_msku, variation_barcode, variation_price, variation_compare_at, variation_cost, variation_quantity

Inventory-only columns

sku, quantity, variation_sku — variation_sku optional; when given, that variation's stock is set, otherwise the product's stock.
